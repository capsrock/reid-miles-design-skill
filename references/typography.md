# タイポグラフィ詳細

## 頻出書体（実例ベース）

Fonts In Use等のアーカイブで確認できる、実際のBlue Noteジャケットで使われた書体:

| 書体 | 用途傾向 |
|---|---|
| Franklin Gothic | 太い見出し、対比用の重い書体 |
| Trade Gothic / Trade Gothic Extended | タイトル文字。1960年代のタイトル拡大期に多用 |
| Clarendon / Craw Clarendon | スラブセリフの存在感ある見出し |
| Bodoni / Ultra Bodoni | 高コントラストのモダンセリフ、太字見出し |
| Futura / Futura Black | 幾何学的サンセリフ、シルエット的な使い方 |
| News Gothic | 中間サイズの実用的サンセリフ |
| Caslon No. 471 & 540 | クレジット・小さい文字の繊細な対比用 |
| Akzidenz-Grotesk | スイス的な素っ気ないサンセリフ |
| Onyx | 極端に細長いコンデンス書体 |
| Beton / Egyptian Expanded | スラブセリフ系のアクセント書体 |
| Haas Inserat-Grotesk | 太いディスプレイ用グロテスク |
| Tempo, Vogue, City, Mistral | 装飾的・筆記体的なアクセント書体（稀に使用） |

## 組み合わせの考え方

- 1枚のジャケットに書体を混在させる時は「太いディスプレイ書体（見出し）」＋「繊細な書体（クレジット・補助情報）」の2層構造が基本
- 同系統の書体を安易に重ねない。グロテスク系の見出しに対して、クレジットはセリフ系（Caslon等）を当てて対比を作ることが多い
- 特定の書体に固定化しない。マイルス自身「一つの書体・システムに落ち着かなかった」（Richard Cook, *Blue Note: The Biography*）とされ、アルバムごとに書体選びを変えている

## 文字の扱い方（配置・加工）

- 大文字＋広いレタースペーシングでフォーマルさや余白感を出す
- 逆に極端に文字間を詰めた表現で密度・スピード感を出す
- タイトル文字を斜めに傾ける、写真の輪郭・被写体のポーズに沿わせる
- 1行の中でサイズを大小混在させ、視線の動きにリズムを作る（音楽的な「間」の表現）
- 写真を使わず、タイポグラフィのみでジャケット全体を構成する回もある（十分な情報量とインパクトを文字だけで作る）
