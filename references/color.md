# 配色詳細

## 基本方針（写真を使わない場合）

- ベースは黒・白・オフホワイトの無彩色
- そこに差し色を1〜2色載せる。フラットな色面として使い、グラデーションにはしない
- 黒と白は常にコントラストの土台として確保する（差し色だけで構成しない）
- 実際のBlue Noteカバーは「青系だけ」ではなく、アルバムごとに全く違う配色を試している。同じ配色パターンを繰り返さないこと自体がスタイルの一部

## 実例に基づく配色パターン（固定化を避けるための引き出し）

海外の資料で確認できる実際のカバーの配色から、代表的な組み合わせを挙げる。案を出すときはこの中から偏りなく選び、同じ組み合わせを繰り返さない。

| 元カバー | 配色 | 印象 |
|---|---|---|
| Dexter Gordon『Go』 | オレンジ＋ブルー（写真は青ティント） | ドラマチックで力強い対比 |
| Andrew Hill『Judgement!』 | グリーン＋ブルーの文字、背景は黒 | シリアスで緊張感がある |
| Freddie Roach『Good Move!』 | ブルーティント＋グリーンとベージュの文字 | 落ち着きつつ効かせ色がある |
| Art Blakey『Moanin'』 | 黄緑がかったイエロー1色のティント | ノスタルジックで温かみがある |
| Wayne Shorter『Speak No Evil』 | コバルトブルー全面＋赤い口紅の差し色 | クールな中に鮮烈なアクセント |
| Kenny Dorham『Trompeta Toccata』 | 赤・ピンク・パープル・オレンジを並べたビビットな多色使い | 派手でエネルギッシュ、数少ない多色例 |
| Lee Morgan『The Rumproller』 | 黒＋赤茶（rust brown）の文字、背景白 | 渋くて力強い |
| Freddie Hubbard『Hub-Tones』 | 黒の柱＋赤いグロー、名前だけ赤茶 | 白背景に一点だけ効かせる |

## 色の使いどころ

- タイトル文字の背景に色面（カラーブロック）を敷き、文字自体は白抜きにする
- 逆に文字だけを差し色にして、背景は黒白のままにする
- 罫線・アイコン・区切り線に差し色を使い、視線誘導の役割を持たせる
- 基本は「黒＋白＋差し色1〜2色」だが、Kenny Dorham『Trompeta Toccata』のように、ここぞという1枚もの（アイコン・スプラッシュ等）では、赤・ピンク・パープル・オレンジのようなビビットな多色を意図的に使ってよい。ただしその場合も黒か白のどちらかを土台として残し、色面同士は必ずフラットな塗りにする

## 実務上のルール

1. 差し色はアルバム（案）ごとに変える。青系だけに固定しない
2. 通常は1〜2色、ここぞという1枚もの表現ではビビットな3〜4色の組み合わせも選択肢に入れる
3. 黒と白は常にコントラストの土台として確保する
4. グラデーションや複雑な色相の混在は避け、フラットな色面で構成する
5. 写真素材は使わない。色面・図形・罫線・タイポグラフィのみで構成する
